SAMURAI WARRIORS 2 (PC) - HD TEXTURES
=====================================
(Français plus bas)

7,392 textures of the game remade in HD (twice the resolution):
characters, officers, soldiers, weapons, scenery, skies, menus, portraits,
loading and story screens. The images were upscaled with AI models on a
home PC and tested in game, keeping the original art style: no new design,
the same images, only sharper.

Works with the English game and with the French translation (their
specific images are included too).

How it works: the game files are NOT changed. A small module
(SW2HD.asi) recognizes each original image when the game loads it and
shows the HD version instead. Any image changed by another mod simply
stays as it is.


REQUIREMENTS
------------
- Samurai Warriors 2, PC version.
- About 6.5 GB of free disk space.
- Tested with an NVIDIA RTX 4070, 60 FPS, normal loading times.


INSTALL
-------
1. Close the game.
2. Download BOTH files from Nexus: "Plugin" and "Textures".
3. Extract both archives directly into the game folder, next to sw2.exe.
   If Windows asks, replace the existing files. You should get:
      ...\Samurai Warriors 2\sw2.exe
      ...\Samurai Warriors 2\dinput8.dll
      ...\Samurai Warriors 2\SW2HD.asi
      ...\Samurai Warriors 2\SW2HD.ini
      ...\Samurai Warriors 2\Textures_HD\  (7,392 .sw2h files + index.bin)
4. Launch the game. That's it: no installer to run.

dinput8.dll is the Ultimate ASI Loader. The Widescreen Fix, the Controller
Mod, the Japanese Voices and the French Translation use the same file, so
replacing it is fine.

Updating from 1.0: extract the two new archives the same way. The old
SW2_HD_Textures folder (with INSTALL.bat) is no longer needed and can be
deleted.


UNINSTALL
---------
Delete SW2HD.asi, SW2HD.ini, SW2HD.log and the Textures_HD folder from the
game folder. Keep dinput8.dll if you use any of my other mods; otherwise
delete it too.


SETTINGS (SW2HD.ini, next to sw2.exe)
------------------------------------
- F11 (in game) switches between HD and original textures, to compare.
- Enable=0      turns the HD textures off without uninstalling.
- Mipmaps=1     smoother distant textures, less shimmering.
- VideoMemory=1 keeps the HD textures in video memory (recommended).
- Log=1         writes SW2HD.log.


TROUBLESHOOTING
---------------
- No HD textures and no SW2HD.log next to sw2.exe: the ASI loader is not
  loaded. Check that dinput8.dll is next to sw2.exe (some antivirus
  programs remove it).
- SW2HD.log exists but has no "Direct3D pret" line: please post the
  log in the comments.
- Windowed or fullscreen, Alt+Tab, launch through Steam or sw2.exe:
  all supported.


COMPATIBILITY
-------------
- French translation, Japanese Voices, Controller Mod, Widescreen Fix:
  compatible, any install order.
- Other mods that replace textures: the images they change stay as they
  are, everything else is in HD.


CREDITS
-------

  4x-UltraSharpV2 models (by their authors).
- Ultimate ASI Loader by ThirteenAG (MIT license).
- No original game file is included, only the upscaled textures.

SAMURAI WARRIORS 2 (PC) - TEXTURES HD
=====================================

7 392 textures du jeu refaites en HD (deux fois plus fines) :
personnages, officiers, soldats, armes, décors, ciels, menus, portraits,
écrans de chargement et d'histoire. Les images ont été agrandies avec des
modèles d'IA sur un PC personnel puis testées en jeu, en gardant la
direction artistique d'origine : pas de nouveau dessin, les mêmes images,
en plus net.

Fonctionne avec le jeu en anglais et avec la traduction française (leurs
images propres sont aussi incluses).

Principe : les fichiers du jeu ne sont PAS modifiés. Un petit module
(SW2HD.asi) reconnaît chaque image d'origine quand le jeu la charge et
affiche la version HD à la place. Une image modifiée par un autre mod
reste simplement telle quelle.


CONFIGURATION REQUISE
---------------------
- Samurai Warriors 2, version PC.
- Environ 6,5 Go d'espace libre.
- Testé avec une NVIDIA RTX 4070 : 60 FPS, chargements normaux.


INSTALLATION
------------
1. Fermez le jeu.
2. Téléchargez les DEUX fichiers sur Nexus : « Plugin » et « Textures ».
3. Extrayez les deux archives directement dans le dossier du jeu, à côté
   de sw2.exe. Si Windows le demande, remplacez les fichiers existants.
   Vous devez obtenir :
      ...\Samurai Warriors 2\sw2.exe
      ...\Samurai Warriors 2\dinput8.dll
      ...\Samurai Warriors 2\SW2HD.asi
      ...\Samurai Warriors 2\SW2HD.ini
      ...\Samurai Warriors 2\Textures_HD\  (7 392 fichiers .sw2h + index.bin)
4. Lancez le jeu. C'est tout : aucun installeur à lancer.

dinput8.dll est le chargeur Ultimate ASI Loader. Le correctif écran large,
le mod manette, la VO japonaise et la traduction française utilisent le
même fichier : vous pouvez le remplacer sans souci.

Mise à jour depuis la 1.0 : extrayez les deux nouvelles archives de la
même façon. L'ancien dossier SW2_HD_Textures (avec INSTALL.bat) ne sert
plus et peut être supprimé.


DÉSINSTALLATION
---------------
Supprimez SW2HD.asi, SW2HD.ini, SW2HD.log et le dossier Textures_HD du
dossier du jeu. Gardez dinput8.dll si vous utilisez un de mes autres mods,
sinon supprimez-le aussi.


RÉGLAGES (SW2HD.ini, à côté de sw2.exe)
--------------------------------------
- F11 (en jeu) passe des textures HD aux textures d'origine, pour comparer.
- Enable=0      désactive les textures HD sans désinstaller.
- Mipmaps=1     textures lointaines plus douces, moins de scintillement.
- VideoMemory=1 garde les textures HD en mémoire vidéo (recommandé).
- Log=1         écrit SW2HD.log.


EN CAS DE PROBLÈME
------------------
- Pas de textures HD et pas de SW2HD.log à côté de sw2.exe : le chargeur
  ASI n'est pas chargé. Vérifiez que dinput8.dll est à côté de sw2.exe
  (certains antivirus le suppriment).
- SW2HD.log existe mais sans ligne « Direct3D pret » : postez le
  journal dans les commentaires.
- Fenêtré ou plein écran, Alt+Tab, lancement par Steam ou par sw2.exe :
  tout est pris en charge.
