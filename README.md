# Samurai Warriors 2 (PC) - HD Textures

Source code of the Nexus Mods release:
https://www.nexusmods.com/samuraiwarriors2/mods/9

7,392 textures of the game upscaled 2x (AI upscale, done locally with chaiNNer) and shown
in game by a small ASI module. No game file is modified, and no original game file is
included in the release.

## What is in the release (version 1.0.1: two files, no installer)

Since 1.0.1 the release is split in two zips, both extracted directly into the game folder
(next to `sw2.exe`). There is no .bat installer any more.

**SW2_HD_Textures_Plugin_v1.0.1.zip** (small, all the program files)

| File in the zip | Source |
|---|---|
| `SW2HD.asi` | built from `src/sw2hd.c` + `src/version.rc` (see Build) |
| `SW2HD.ini` | `package/files/SW2HD.ini` (plain text) |
| `SW2HD_readme.txt` | `package/readme.txt` (plain text) |
| `dinput8.dll` | unmodified Ultimate ASI Loader by ThirteenAG (MIT): https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases (Win32 build) |

**SW2_HD_Textures_TexturePack_v1.0.1.zip** (large, data only, no program)

| File in the zip | Source |
|---|---|
| `Textures_HD/*.sw2h`, `Textures_HD/index.bin` | data files: the upscaled textures (DXT1/DXT5/BGRA pixel data with a small header), generated by `tools/sw2_hd.py` |

The release contains **no executable code other than `SW2HD.asi` and the unmodified `dinput8.dll`**.

## What SW2HD.asi does

It is loaded by the ASI loader at game start and works **in memory only** (`sw2.exe` is never modified):

1. Reads `Textures_HD\index.bin` (list of CRC32 fingerprints of the original textures).
2. Hooks `Direct3DCreate9` (in d3d9.dll) and then a few `IDirect3DDevice9` / `IDirect3DTexture9`
   methods: `CreateDevice`, `Present`, `CreateTexture`, `SetTexture`, `SetSamplerState`, `Reset`,
   and the textures' `Lock` / `Unlock` / `Release`.
3. When the game fills a texture, it computes the CRC32 of the original pixels. If an HD version
   exists, it loads `Textures_HD\<crc>.sw2h` into a new texture, and `SetTexture` binds the HD
   texture instead of the original one.
4. F10 writes the list of HD textures on screen to `SW2HD.log`; F11 switches HD on/off.

No network access, no registry access, no file written except `SW2HD.log` in the game folder.

## Build

### SW2HD.asi
Needs Python 3 and the Zig toolchain from PyPI (`pip install ziglang==0.17.0`).
No Visual Studio, no Windows SDK.

    cd src
    build.bat         (Windows)
    ./build.sh        (Linux / macOS)

Rebuilds are not byte-for-byte identical (build metadata differs), but they come from this exact source.

### Textures
`tools/sw2_hd.py` extracts the textures from your own copy of the game (`extraire`, `extraire_us`),
and after upscaling (chaiNNer: 1x-DXTless-SourceEngine, then 4x-UltraSharpV2, resized to 50 %)
writes the `.sw2h` files and `index.bin` (`module <folder>`). The game files are not included.

### Release zips

    python build_tools/creer_mod_hd.py --version 1.0.1

(expects `readme.txt` and `files/SW2HD.asi` + `files/SW2HD.ini` next to it; takes `dinput8.dll` and the textures from the game folder; writes the Plugin zip
and the Textures zip).
